# Aitumalow 0.4.0 release notes

Release target: `v0.4.0`.

## Visual workflow editor

The editor now gives the graph more room, with searchable actions, category
filters, floating settings, and separate run-history and version panels. Use
**+** below an unconnected output to add and connect the next action. A failed
connection can be retried without creating the action again.

Workflows flow from top to bottom by default. Branches spread horizontally,
inputs enter above each step, and outputs leave below. Existing saved positions
are preserved: use **Auto Layout** to rearrange an existing graph vertically.
Opening and closing the picker preserves unsaved settings for the current step.
The internal entry points and host-registered capability model are unchanged.

## Durable Workflow upgrade

The minimum runtime is now `durable-workflow/workflow:^2.0.9`, replacing the
`2.0.0-rc.52` pin in Aitumalow 0.3.0. The development installation moved from
2.0.3 to 2.0.9.

The [upstream patch releases](https://github.com/durable-workflow/workflow/releases)
address suspended-Fiber cleanup, early timer/activity delivery, metadata
projection, child completion, and replay of terminal activity timeouts. Child
repair can wake stranded parents without repeating completed children. Already contradictory terminal histories
are not automatically rewritten, and cancellation does not automatically run
application cleanup.

## Compatibility and host upgrade

PHP 8.4+, Laravel 13, and Filament 5 requirements are unchanged. No Aitumalow
schema, host API, snapshot format, or replay identity change is introduced.
The 2.0.3-to-2.0.9 source comparison found unchanged dependency requirements
and migration files. The public adapters used here need no signature changes.
The runtime remains embedded; this update does not require a standalone server.

After the release is published, update the host explicitly because `^0.3.0`
does not include `0.4.0`:

```bash
composer require aitumalow/aitumalow:^0.4.0 --with-dependencies --minimal-changes
php artisan migrate
php artisan workflow:v2:doctor --strict
php artisan filament:upgrade
```

Restart long-running workflow workers through the host's normal deployment
process so they load the updated runtime. Verify a representative workflow,
including wait/resume and failure handling, in the host before enabling traffic.
Hosts using pre-v2 histories must follow Durable's drain/coexist migration path.

Compiled standalone and embedded editor assets are included in the package.
